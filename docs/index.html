Introduction

Calibrating a multi-camera rig against a marker field is usually posed as one large bundle problem in which every marker pose and every camera pose is estimated at once. The cameras on a vehicle, however, rarely share a view: a forward telephoto and a rear fisheye may never observe the same board, so the estimate that ties them together is carried entirely by the marker map between them.

This work separates that map from the cameras that use it. The marker field is solved first and then held fixed, so each vehicle camera is registered against a reference that does not move while it is being estimated. What the map is worth is then a question about the observations that built it, which is where the second element comes in: each marker observation carries a full pose covariance derived from the image, not a hand-tuned scalar weight.

Method

Three stages run in order. Each one treats the output of the previous stage as fixed, so the variables being solved shrink as the reference they are solved against becomes better determined.

Stage 1

Environment markers

Tag detections are merged per board, relative poses are collected as marker-to-marker pairs, and the marker map is solved with Levenberg–Marquardt.

Stage 2

Wheel markers

Wheel-board observations extend the frozen environment map with the markers that define the vehicle frame.

Stage 3

Vehicle cameras

Each camera enters as a new node against the frozen map, and its extrinsics are reported in the vehicle frame.

Observation uncertainty

Every observation carries a full 6×6 pose covariance instead of a scalar weight. Corner-level uncertainty is estimated from the image structure tensor, then propagated through the perspective-n-point solve by an unscented transform. The resulting covariance reaches the solver unchanged, off-diagonal correlation terms included, so a board seen at a shallow angle or far from the image centre contributes proportionally less than one seen square-on and close.

Observation filtering

Outliers are removed one observation at a time rather than by discarding whole images.

  • Marker pairs co-observed fewer times than a threshold are dropped, and only the observations of the less-observed marker in that pair are removed. A marker left with no pairs falls out of the optimization.
  • Vehicle observations that disagree with the frozen marker map beyond a rotation and a translation threshold are excluded before the solve.

Camera models

Pinhole and fisheye (Kannala–Brandt) cameras are handled in the same run, so a rig mixing wide-angle and telephoto units needs no separate pass.
